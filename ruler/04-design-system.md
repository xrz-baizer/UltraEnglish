# macOS 界面与设计系统

### 主题精简与文字亮度（2026-11-13）

- 浅色界面的选中文字、导航强调文字、菜单勾选使用蓝灰色 `--primary-ink` / `--accent-foreground`，学习正文使用独立的文字颜色。
- 深色正文与图标亮度适度下调，正文前景亮度为 82%、次要文字为 65%；增强对比度时恢复更高亮度，不改动现有背景、材质或组件布局。
- 仅提供浅色、深色与跟随系统；移除护眼选项及配色，历史值兼容切回浅色。
- 侧栏使用透明的 `ultra-english-mark.svg` U/声波符号，独立输出本地资源以符合现有 CSP；认证与系统安装图标继续使用方形应用素材。

### 章节设置与统一下拉菜单（2026-11-13）

- 章节设置两行间距为 10px，每词重复触发器常规高度 36px，字号放大时适度扩展宽度以保持全局值可读。
- 过滤熟词采用与笔记和自动播放一致的 44×26px 滑动开关，保留可点击文字标签、`role="switch"` 与 `aria-checked`，继续使用原过滤状态。
- 重复次数和音频分类编辑、筛选、排序使用共享 Select：实色触发器、细边框、统一箭头、磨砂菜单、选中勾选及悬停高亮。复用主题圆角/阴影/强调变量，长列表限制高度并支持键盘滚动；减弱透明度或增强对比度时弹层降级为实色。

### 拼写文字颜色与字号（2026-11-24）

- 单词和释义在浅色主题用黑色，深色主题用正文前景色。例句沿用主题配色。正确、错误的状态色各有默认值和重置按钮。
- 拼写训练的「显示设置」包含字体、文字样式与状态颜色。单词字体与字重的下拉框对齐；单词、音标、释义、例句字号使用左减右加控件，保留中间的精确输入。练习页的音标旁使用无底色的 SVG 发音按钮。

## 设计定位

应用类型是“资料库 + 学习工作区”。主窗口侧栏先展示首页，再按生成音频、跟读训练、拼写练习排列功能入口；设置与账户放在侧边栏底部。书籍详情进入章节练习，音频详情进入听力工作区。内容通过标题、间距和分隔线组织，避免把每段文字做成一张卡片。

设计参考 macOS 原生应用，使用冷灰背景、白色内容面板、系统字体、单一蓝色强调。`apple-liquid-glass` 提供主要视觉原则，`macos-app-design` 补充窗口、菜单、快捷键和无障碍规范。

## 材质与实际能力

- 2026-11-13 按用户要求将磨砂扩展到主面板背景（含拼写练习底色），并进一步增强侧边栏透明感，适配浅色和深色。主面板色层不透明度为 54%；侧边栏为浅色 18%、深色 28%，这些是叠加在系统原生磨砂之上的 CSS 色层，不代表整个窗口的最终透明度。
- 主窗口默认以 1400×800 普通窗口启动，不自动最大化；用户可自行使用系统放大/全屏。最小尺寸为 1000×600。
- macOS 主窗口：`hiddenInset` + 系统红黄绿按钮 + `vibrancy: 'sidebar'` + `visualEffectState: 'followWindow'`，窗口底色透明。
- renderer 的 `html`、`body`、窗口根壳保持透明；侧边栏半透明，才能透出 AppKit 提供的系统材质。不能在根壳再铺一层全屏实色背景。
- `app-workspace` 在 macOS 使用半透明主题色与磨砂滤镜，透出窗口原生材质；拼写练习根背景透明，复用同一层工作区磨砂，不单独再叠加滤镜。工具栏覆盖滚动内容时保留既有磨砂；只有内容实际滚过时才出现底部分隔线。
- 词汇列表、音频表格、字幕面板及输入控件保留实色内容面。练习单词和释义直接显示在工作区底色上，保留既有字体、字号及主题文字配色；不要为独立内容卡片增加 backdrop-filter。
- `main/window-appearance.ts` 统一响应系统减弱透明度与增强对比度；renderer 通过窗口信息及变化事件获得状态。
- Windows/Linux 保留原生标题栏、使用实色侧边栏，不绘制仿 macOS 按钮。
- `--workspace-fill`、`--workspace-filter`、`--practice-fill` 统一控制主面板与拼写背景；系统减弱透明度、增强对比度或滤镜不可用时恢复实色。Windows/Linux 主面板及拼写背景也保留实色。

**能力边界**：当前 Electron 34 的公共 vibrancy 是 AppKit 原生磨砂材质；工具栏与覆盖层由 CSS 补充。它不是对 macOS 26 `NSGlassEffectView` 折射效果的直接桥接。不要在文案或交付中把现有实现描述为原生折射 API。将来若引入原生扩展，需单独核验系统版本、签名、分发与降级，不能把该扩展作为普通界面改动隐式加入。

参考：[Electron BrowserWindow 官方文档](https://www.electronjs.org/docs/latest/api/browser-window)。实现时仍须以当前安装版本的类型定义验证兼容性。

## 设计变量

实际变量位于 `src/renderer/styles/globals.css`，Tailwind 通过 `tailwind.config.js` 复用 HSL 变量。不要直接复制其他设计库同名但格式不同的变量，例如本项目 `--accent` 是 HSL 通道，不能替换成十六进制颜色。

| 用途 | 约定 |
| --- | --- |
| 浅色底 | `--background`，约 `#f5f5f7` |
| 内容面 | `--card`，浅色为白色 |
| 正文与次要文字 | `--foreground`、`--muted-foreground` |
| 强调、焦点与主操作 | `--primary`、`--ring`，单一蓝色 |
| 细分隔线 | `--hairline`，浅色为 `rgba(0,0,0,.07)` |
| 小标记/封面 | `--r-chip: 6px`、`--r-thumb: 12px` |
| 覆盖层/面板 | `--r-sheet: 16px`、`--r-card: 18px`、`--r-panel: 22px` |
| 大焦点区/胶囊 | `--r-hero: 26px`、`--r-pill: 999px` |
| 阴影 | `--sh-card`、`--sh-panel`、`--sh-overlay`，柔和双层 |
| 窗口框架 | 展开侧栏 224px，收起 92px，工具栏 64px |
| 内容宽度 | `--max-content: 1080px`，水平居中 |
| 动效曲线 | `--ease-spring`、`--ease-out-quart` |

字体使用系统 SF / PingFang 栈。标题适度负字距，正文保证阅读行高，计数和进度使用 tabular-nums。小型元信息不能承担主要操作含义；学习单词和释义仍尊重用户字号、字体、颜色与位置偏好。

提供浅色、深色和跟随系统。主题切换同时更新原生窗口外观；跟随系统时监听媒体查询变化，不只在启动时判断一次。历史护眼值归一化为浅色。

## 组件与布局

- `.surface-panel`：同类条目共用面板与细分隔线。
- `.primary-button` / `.secondary-button`：操作按钮，最小高度 44px；一个区域突出一个主要操作。
- `.icon-button`：44px 命中区域，图标可更小，必须有名称。
- `.book-row`：整行导航或选择；内置词库在管理态不可选择。
- `.category-segments`：单选分类，选中状态可读，不只以颜色表达。
- `.search-field`：明确 label、真实过滤、可清除和空结果状态。
- 练习页集中显示当前单词与释义，长内容允许滚动，不能把单词挤到窗口外。
- 工具栏和侧边栏空白区域允许拖窗；按钮、链接、输入使用 `no-drag`。

## 动效与无障碍

- 静态内容直接显示，避免整个页面淡出再淡入。不要在异步列表上加入逐行入场动画。
- 反馈限于轻微按压、悬停背景、覆盖层开合，通常 180–300ms。避免装饰性循环、发光和大面积移动。
- 动画以 transform/opacity 为主，不以宽高动画造成布局抖动。
- 尊重 `prefers-reduced-motion`、`prefers-reduced-transparency`、`prefers-contrast`，并使用原生可访问性状态兜底。
- 可见键盘焦点、语义标签、筛选 `aria-pressed`、侧栏 `aria-expanded`；不能只靠颜色表示状态。
- 弹窗使用共享 Radix Dialog 维持焦点锁定、Escape 关闭和焦点恢复。遗留手写 portal 弹窗仍需在后续触及交互时迁移，不能仅靠视觉样式宣称已满足全部读屏要求。

## 界面文案与品牌

- 用布局、图标、层级和控件位置表达功能，避免用说明性文字解释界面。删除宣传口号、重复标题、装饰性副标题，例如“专注每一点进步”“把喜欢的声音变成学习素材”“你的英语学习空间”。
- 保留必要的操作名称、数据、状态、错误原因、输入约束与模型选择差异；不能为了减少文字而删掉用户解决问题所需的信息。
- 首页与文字转音频和音频资料库共用页头结构及内容边距，两个音频页面占满主内容区并保留等量的上下内边距。首页的文字转音频、音频资料库和词汇资料库使用等宽卡片，上方展示文本声波、耳机声波和键帽插画，下方以列表说明功能。悬停或键盘聚焦时播放短暂动效，开启系统减少动态效果时显示静态插画。窄内容区改为单列，学习进度面板在卡片下方展示三项统计。
- 生成音频页沿用训练页面的页头和内容边距，标题区支持拖动窗口。标题下方的操作栏左侧放置模型、音色、输出格式和语速，右侧放置生成记录和加宽的绿色「生成」按钮，紧凑窗口允许换行。选项标签使用淡色常规字重，文件大小和状态显示在展开的下拉列表中。生成音频设置中，语音模型、音色和存放路径各有标题与卡片。模型和音色采用跟读训练模型列表的单选、选中底色和右侧下载操作。文本框占满剩余空间，用主题底色区分。输入字号默认 24px，字号控件与字符数以相同的淡色样式位于文本框下方同一行。生成记录弹窗只滚动列表。语速控件以主题底色提示键盘焦点。语速和字号采用同样的左右加减控件。模型或音色未就绪时在对应控件以边框、文字和焦点提示，系统未启用减弱动态效果时再短暂晃动。结果弹窗把文件摘要和试听放在同一面板，导入为主操作。语音资源下载与合成复用居中的进度弹窗，通过旋转图标和阶段文字反馈。启用减弱动态效果时保留静态图标和阶段文字。输入区、设置及弹窗复用主题变量，并保留键盘焦点。
- 词汇与音频资料库的操作组位于标题右上方；窄窗口允许换行并保持右对齐。主内容不要堆满左侧。
- 品牌图标统一使用 `assets/icons/icon.png`，macOS 分发使用同目录 `icon.icns`，Windows 使用 `icon.ico`。Lucide 只用于功能图标，不能替换品牌 logo。
- 全局文字默认 110%，基础设置支持 90%–150%，步长 5%。`basic.fontScale` 经 `--font-scale` 缩放 CSS/Tailwind 字号，根 rem 保持 16px，不借助 zoom 放大间距；现有整页缩放与练习字号设置独立保留。
- 设置在窗口中心淡入，不使用会覆盖居中 transform 的位移动画。标题和关闭按钮放在不可滚动的标题栏，只有内容区滚动；Esc 和键盘焦点行为保留。

## 后续调整边界

- 不以界面精简为由改掉用户认可的工作区结构。音频页的左字幕、右单句、下音轨和逐词/选词播放是核心约定；移除录音不代表移除其他学习功能。
- 字号调节在滑杆外提供 −10%、+10%、恢复默认，以及 100%、110%、120%、125%、150% 快捷按钮；边界禁用，百分比保存在基础设置。
- 拼写页顶部操作不足一行时换行，禁止用横向滚动承载主要按钮。隐藏释义时取消释义容器内部滚动约束，不用大高度占位撑出滚动条。
- 侧栏降低填充不透明度，让原生 vibrancy 可见；工具栏增加细亮边和磨砂层次，选中项保留现有强调色。学习内容卡片不叠加玻璃，拼写页复用主面板磨砂底色。系统减弱透明度/增强对比度仍降级为实色。

## 紧凑布局与护眼主题补充

- 护眼主题选中导航使用深绿色文字和图标，禁止白字配浅绿底。顶部固定标题与资料库面包屑提高字号。
- 侧栏品牌只保留放大的软件名称；概览用单一大号蓝色书本图标。资料库外侧留白缩小，音频表格单元格增加内边距。
- 页面字号与整页缩放统一控件样式：减 10%、重置、加 10% 在左侧，当前百分比靠右，不再展示预设百分比按钮。
- 音频页移除字幕导入、媒体信息页签和下载按钮；左侧直接显示字幕，右侧文本左对齐、紧凑行高并按句末标点换行，底部音轨减高。

## 音频学习细节（2026-11-11）

- 默认浅色主题使用暖珊瑚色强调色，保留白色内容表面；波形读取主题变量，不能单独写死蓝色。
- 页面字号和界面缩放滑块使用一致的进度色；减小、重置、增大和当前百分比位于滑块上方。
- 左右字幕区域隐藏滚动条，但保留滚轮和触控板滚动。
- 右侧句子顶部左对齐；按标点换行仅影响展示，不改变字幕分段。
- 辅助按钮浮于右下角，包含复制、字号、整句音标和词下笔记开关。所有句子/词组笔记仍完整列在句子下方；词下展示为额外开关。
- 音轨选区使用两条 2px 红色边界和淡红色填充；边界拖动命中区域透明，不添加第二层粗色块。
- 无字幕时使用带全窗口遮罩的弹窗提供生成、输入和导入字幕，添加后显示播放工作区。已有字幕时，替换前保留确认步骤。

字幕排版补充：恢复单词左右 3px 留白，保留紧凑行高 1.18；不扩大字幕面板比例。音频字幕默认 Arial、常规 400，可在设置中选择加粗 700。已保存的字体选择保持兼容。
