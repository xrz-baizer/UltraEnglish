# 功能、数据与现有边界

## 主题兼容与播放控件位置（2026-11-13）

- 可选主题仅为浅色、深色、跟随系统。ThemeProvider 将历史护眼本地值归一化为浅色并更新本地键；settings-store 同步归一化旧数据库偏好，有新版嵌套主题时优先于旧平铺字段。
- 自动播放开关位于音轨左侧循环播放按钮之后，保留开关状态、切句控制及鼠标点击后空格播放/暂停行为。

## 章节开关及下拉控件（2026-11-13）

- 单书每词重复仍保存到 `book_settings_<bookId>`，保留跟随全局和 1–5 次，改用共享下拉菜单；全局空值映射只发生于组件内部，业务存储键及字段不变。
- 熟词过滤改为滑动开关，标签也可点击，原 `vocab_filter_familiar_<bookId>` 的持久化与过滤逻辑保持一致。
- 音频修改分类、分类筛选及排序共用下拉组件；保留未分类空值、保存/取消及原排序语义。菜单 Esc 先关闭选项弹层并返回触发器，不连带关闭分类对话框。

## 拼写颜色设置简化（2026-11-13）

- 单词设置中移除单词、释义、例句三个颜色入口，只保留正确和错误颜色；字体、字号、字重及例句关键词加粗设置继续保留。
- 历史 `wordColor` / `definitionColor` / `examplesColor` 仅保留读取兼容性，不再影响练习渲染；默认设置不再创建这三个字段，不进行破坏性数据迁移。
- 填空与默写均由主题决定普通文字颜色：浅色为绿色，深色为柔和近白色；正确、错误颜色仍即时应用并持久化。

## 切句自动播放与重复次数（2026-11-13）

- 音轨下方左侧提供“自动播放”滑动开关，状态保存于 `audio.autoPlayOnSentenceChange`，默认关闭，旧设置缺少此字段时合并默认值。
- 左/上切到上一句，右/下切到下一句；方向键、上一句/下一句按钮及右侧字幕点击统一通过同一切句逻辑，由自动播放开关决定是否从句首播放。替代此前“左右播放、上下静默”的约定。
- 关闭自动播放时切句会暂停；启用时切句后播放，适用于单句与全文模式。关闭开关取消尚未开始的切句播放请求，但不主动中断已在播放的当前句。鼠标点击开关后释放焦点，空格继续播放/暂停；通过键盘聚焦开关时，空格保留原生切换开关行为。
- `lib/vocabulary-repeat.ts` 统一每词重复次数范围 1–5；全局设置滑块、单书设置和练习页共用范围。单书保留“跟随全局”选项和原存储键，历史超限值读取时限制到有效范围，不清空其他设置。

## 首页

入口 `pages/home.tsx`，通过 `electronAPI.getLearningOverview()` 调用主进程 `learning-overview`。

- 展示词汇书数量、音频数量、至少正确输入过一次的词条数量。
- 词条统计来自 `WordProgress.correctCount > 0`，不等同于掌握数、熟词数或完整章节数。
- 首页依次提供生成音频、跟读训练和拼写练习三个入口，与侧栏进入相同的功能主页，分别对应 `/audio-generation`、`/audios` 和 `/vocabulary`。底部显示三项学习统计。
- 概览失败显示重试，不把错误当成全零。

当前练习页主要维护 `word_progress` 和本地章节键；已有 `createPracticeRecord` IPC，但练习完成流程未完整接入该记录接口。因此“最近章节记录”只反映数据库实际已有记录，不能宣称覆盖全部历史练习。后续若补全记录写入，应明确去重、恢复与重复完成语义，并独立验证。

## 词汇资料库

入口 `pages/vocabulary/index.tsx`。

- 默认分类为雅思、四级、其他，并保留自定义分类。必背、只读分类已移除；后续明确要求保留的雅思王 C5、C11 归入默认雅思词库。
- 默认导入五本词库：雅思分类中的雅思王 C5、C11，以及其他分类中的基础词汇、COCA 3000-6000 和阅读核心词汇。启动时按稳定 ID 补齐缺失词库。旧分类迁移前保留这五本书及其已有词条和学习进度。
- 名称/描述搜索、分类筛选可组合；总览数字反映整个资料库，不随搜索结果混淆变化。
- 标题、管理操作、分类筛选和搜索固定在视口内，下方单词本列表独立滚动。
- 分类管理支持拖动手柄排序、上下按钮及手柄上的方向键。顺序自动保存到 `settings.vocabulary.categoryOrder`，筛选栏、分组列表和独立导入窗口通过 `lib/vocabulary-categories.ts` 共用该顺序；新增分类追加，失效名称忽略，默认分类可移动但不可删除。旧设置缺少顺序时沿用默认分类加自定义分类的顺序，保存失败恢复并提示。词库分类发现等待设置加载完毕后才允许保存，防止启动时默认空顺序覆盖已有顺序；调整后列表和筛选栏回到起点，隐藏滚动条但保留滚动。
- 自定义词库通过独立导入窗口选择 JSON、名称、分类、单词/句子类型。
- 管理模式支持选中自定义词库、移动分类与批量删除。内置词库不可选、不可删除。
- 导入窗口成功后发送 `vocabulary-books-updated`，已打开页面按需刷新。
- 分类管理是词汇库现有功能。音频分类编辑没有完整的模型与写入链路，不应显示无行为按钮或把它写成已完成功能。

## 书籍详情与练习

- 书籍详情展示词条数、章节、进度、熟词计数，支持章节长度和重复次数设置。
- 支持熟词过滤、熟词导出到下载目录、重置进度与熟词标记。
- 详情将书名、词数、章节数和熟词数压缩在同一摘要区域；右侧只显示 50/100/200 三个章节长度按钮和重复次数下拉框。历史其他章节长度继续生效并显示当前值，不自动重分章节。熟词过滤放在章节标题旁，导出熟词、清除熟词和全书重置收进“更多操作”；重置仍经共享 Dialog 确认，单章重置与练习链接分开。默写输入框保留底线，聚焦时强调底线。
- 练习支持填词/默写、释义开关、英美发音、前后词导航、重复练习、熟词标记与侧栏列表。
- 练习页不再单独展示字体控件；“设置 → 拼写训练设置 → 拼写字体”统一管理字体族、24–72px 精确字号和字重，字号支持数字输入并在提交时校验范围。单词字重支持 400/500/600/700，旧字重保留；填词文字、默写提示和实际输入同步应用，控件中的键盘输入不进入练习答案。
- 长释义和例句可滚动，输入/当前词条必须保持在可见工作区内。
- 继续兼容已保存的字体、字号、颜色、随机顺序和发音偏好，不在视觉改版中重置它们。

持久化分工：

| 内容 | 位置/键 |
| --- | --- |
| 词库、单词 | SQLite `vocabulary_books`、`words` |

## 音频资料库与工作区

入口 `pages/audios/index.tsx`、`pages/audios/detail.tsx`。

- 无修饰键的左/右方向键切上一句/下一句并自动播放，上/下方向键仅切换并保持暂停；单句和全文模式一致，静默切句取消待播放请求。单句波形须确认当前源已加载完毕再执行自动播放，不能继承前一句的就绪状态。空格切换播放/暂停。字号控件鼠标操作不夺取焦点，空格也能从已聚焦的字号控件进入播放。输入框、弹窗、滑块与分隔线保留自身键盘行为，Shift+左右扩选和系统编辑快捷键保留。
- 两侧字幕以 `segment.text` 为正文依据并统一空白、使用相同字体族；左侧移除标点强制换行与额外空格，单词保持原有紧凑间距，选中背景使用更清楚的绿色并保留播放红字。已有 `words` 仅在文字一致时用于精确时间；不一致时按正文重新估算词时间，避免显示过期文字，不改写原字幕数据。

- 添加资源时先在弹窗选择一个音频文件，再确认名称及分类。手动填写的名称优先，留空时使用去掉扩展名的文件名。确认后主进程才复制文件并创建记录。默认目录为 `app.getPath('userData')/audios`，用户可用 `audioStorageDirectory` 设置后续导入位置。已有记录继续使用原 filePath。
- 资料库右上角“打开存储文件夹”调用无路径参数的 `openAudioStorageFolder()`，主进程创建/打开上述目录，不打开单个音频文件，也不接受任意外部目录。
- 音频列表按表格可用高度、表头和行高计算每页能显示的完整行数，随窗口和字号变化重新计算。搜索和分类筛选后的结果放不下时才显示翻页控件。结果变化时调整页码，「管理」模式显示当页的复选框，选中音频后才显示删除。表头全选作用于当页，退出管理时清空选择。删除记录沿用现有行为，磁盘中的音频副本继续保留。
- 工作区保留左侧滚动字幕/媒体信息、右侧可换行单句、底部当前句波形三部分。保留播放/暂停、前后句、循环、0.7/0.8/0.9/1/1.25 倍速、波形缩放、字幕导入/导出/复制、字幕字号和本地句子笔记。音轨右下角音量滑块范围为 0%–100%，当前播放页的单句、全文及切句共用同一音量。
- 单击词播放该词；按住拖过连续词选择区间并播放，Shift+方向键扩选、Enter 播放选区。生成字幕使用 whisper.cpp `-ojf` 词级 token 时间戳，合并子词与标点后保存 words。播放时用实际媒体时间高亮当前词。
- 旧字幕/SRT/VTT 缺少词级时间，使用有明确“估算”标记的比例时间，重新生成字幕才有模型词级时间。禁止固定高亮第一个词或宣称估算为精确对齐。
- `useAudioClip` 将当前句裁成内存 PCM，波形展示/点击/拖动与播放共用句内时间；渲染器比较字幕时间时加句子起点。切换片段时释放旧 Blob 与播放器，读取原文件失败时保留资料。
- 笔记保存在 localStorage 的 `audio-note:<audioId>:<segmentId>`，不依赖服务端。
- “生成字幕”使用本地 FFmpeg 将音频转换为 16kHz 单声道 PCM，再调用 whisper.cpp CLI，以英语识别并保存带时间戳的片段。音频不会上传；临时 WAV/JSON 在任务结束时清理。
- 引擎随应用资源打包：`assets/bin/whisper/{arm64,x64}/darwin/main`。FFmpeg 从打包 bin、PATH、常见 macOS 安装目录查找；本机已有 `/opt/homebrew/bin/ffmpeg`。macOS 其他机器需安装 FFmpeg（例如 `brew install ffmpeg`），Windows/Linux 还需提供适配平台的 `whisper-cli`。不得宣称已验证这些平台或打包后无需运行依赖。
- 音频设置只呈现模型存储目录、默认音频存储目录和识别模型列表；移除该面板的音量控制。模型通过 `sttModelId` 选择，默认 tiny；下载目录由 `sttModelsDirectory` 控制并在启动时恢复。兼容历史 `sttModelPath`，显式选择模型时清除历史文件覆盖。
- 目录由系统选择器获取，主进程检查读写权限后持久化。取消不改变路径，不自动搬迁原音频或模型。模型目录变更期间不允许同一面板启动重复目录选择。
- 转录缺少模型、引擎、FFmpeg、无语音或执行失败时提供明确错误；保留原音频与已有字幕。重新生成更新同一字幕记录。识别精度及断句以本地模型结果为准。

## 生成音频

- 侧栏与首页进入 `/audio-generation`。初始使用 MP3 和高质量 FP32，仍可选择标准 Q8、WAV、语速和英文音色。模型和音色下拉框分别显示大小、就绪状态及下载入口。缺少资源时，生成操作提示并聚焦对应选择框。用户主动下载并再次点击生成，确认名称和保存位置后启动合成。确认窗口可单独选择本次保存目录，保存失败可更换目录后重试。下载与合成使用旋转进度弹窗，下载可在弹窗中取消。任务结束后弹窗关闭并显示对应结果或错误，下载失败和取消时保留输入。
- 「设置 → 生成音频设置」分别列出语音模型和音色，支持独立下载，并将单选结果与生成页同步，保存至 `audioGeneration` 设置。存放路径单独成组，可分别选择和恢复模型存放路径及音频默认保存路径。默认使用应用数据下的 `models/speech-synthesis` 和系统下载目录。
- 英文文本校验允许英文字母、数字和常用英文标点，要求至少一个英文字母。输入字号可独立调整。语速默认 1×，通过加减按钮在 0.8×–2× 之间每次调整 0.1×。
- 生成后可试听、定位文件或把音频与原文字幕一键导入资料库。MP3 使用支持 `libmp3lame` 的 FFmpeg，失败时可将本次音频改存 WAV。重复导入会打开已有资料，避免重复入库。保存失败可修正输出路径后重试。字幕优先按空行分组，否则按英文语句分段，时间以合成采样为准。

- 操作栏的生成记录按钮打开弹窗，按时间倒序显示最近十条。新生成会弹出结果，重新进入页面只恢复记录。历史记录可主动查看结果、试听、导入或打开已入库详情。

## 导航与练习操作

拼写练习操作分区（2026-11-13）：上一个单词靠左、下一个单词靠右，释义、默写、标记和跳转居中；窄内容区域自动将中间操作换到下一排。操作继续使用既有处理函数和快捷键，键盘顺序为上一个、中间操作、下一个。

主侧栏顶部增加应用图标、名称及随语言切换的“学习工作区”说明，四项导航位于品牌区下方。收起状态保留图标和导航可访问名称。「收起」和「展开」共用主内容区左上角的图标按钮，紧贴侧栏分隔线。设置入口位于侧栏底部。

## 设置与账户

设置由共享 `SettingsModal` 承载：通用、拼写训练设置、跟读训练设置、生成音频设置、快捷键。设置保存失败遵循 store 原有回滚行为；主题与语言变化应即时反馈。快捷键分为单词练习、音频播放两个页签，每项展示操作、按键和具体说明。单词页保留五项已实现绑定的录制与恢复默认，补充删除、默写检查和句子填词确认；仅修饰键和无修饰字母不录入，Esc 取消录制且不关闭设置。音频页列出固定播放/暂停、左右自动播放切句、上下静默切句、清除选区、扩选/播放选区、复制和聚焦分隔线调整；输入框及弹窗保留各自的键盘操作。

当前 `auth-*` 主进程处理器是占位实现，未接入真实登录服务。保留已有入口，但不得把它宣称为已完成的远端认证或同步。本地核心流程不等待服务端。

## 不属于当前任务

服务端/API/JWT 重新开发、云同步、录音能力补全、全新的学习算法、数据库引擎替换、付费系统、发布与签名均需独立明确任务；不能以“设计完善”为由顺带加入。

### 音频选区与笔记约定（后续修订）

页面只展示生成字幕，不再展示导入、媒体信息与导出入口。拖选音轨可播放任意句内区间；词组选区和音轨选区互斥，以后选择者为准，播放按钮复用当前选区。波形定位考虑放大后的宽度和滚动偏移。
循环边界与暂停恢复位置独立保存，暂停后继续不能缩短循环区间；自然结束和区间暂停均处理循环，并避免重复启动。
笔记有两个维度：整句沿用 `audio-note:<audioId>:<segmentId>`；词组使用该键加 `:words:<from>-<to>`。选区变化加载对应笔记，不覆盖整句记录。支持单词和连续多个词的连读标注。

### 字幕、选区与多条笔记修订

- 字幕时间片段由模型及原参考实现的续句合并规则决定；取消 80 字符强制截断。右侧逗号、句号、问号等换行只改变显示，不拆分数据库中的字幕。
- 右侧内容左上对齐，整句与词组笔记在同一滚动面板中始终列出。笔记支持多条、新增、编辑、删除和显式“保存笔记”，只有保存成功才更新持久化；兼容旧单条笔记键。
- 多条笔记保存在 `audio-notes:<audioId>:<segmentId>`；每条记录含 id、text、label 和可选词范围 from/to。
- 鼠标拖选、Shift 点击/方向键扩选都会同步音轨选框。左右边界支持拖动调整，底部播放按钮统一播放当前音轨范围；选中本身不自动播放。Esc 与切句清除选区。
- 修改音轨模式加载整条音频，可拖动当前字幕范围或输入秒数，保存后更新对应字幕 startTime/endTime；取消不持久化。修正后的时间范围控制之后的句子裁切。
- 移除单独选词播放按钮和估算提示，字号/复制工具悬浮放置，不占笔记区域。内部仍兼容没有词级时间的旧字幕，不能把估算时间称为精确对齐。

音轨选区必须高于 WaveSurfer 内部绘制层；验证时使用真实鼠标事件检查手柄命中和数值变化，不能只检查选框是否存在。

### 音轨与音标补充（2026-11-11）

- 剪刀按钮紧邻播放按钮右侧，在当前大小的波形上编辑句子起止；裁切范围为当前句前后各 3 秒，超出文件边界时截断，不显示整段音频编辑栏。
- 单词选择（含 Shift 多选）同步到音轨；音轨拖选/边界微调反向选中重叠的词。播放以最后设置的精确音轨时间为准；Esc 或切换句子清空选择。
- `services/phonetics.ts` 通过 FFmpeg 裁切句子并调用 Echogarden DTW 对齐取得 phone 时间线，拼接整句 IPA；不是逐词查字典。`sentence-ipa` IPC 校验句子是否仍存在且未变化后，缓存到字幕段的可选 `ipa` 字段；生成失败不改变字幕。
- 音标首次使用可能下载 Echogarden 语音资源，此后使用本地缓存。Echogarden 2.3.5 包声明 GPL-3.0，新增依赖的许可证应纳入分发清单；未更改项目自身许可。`wasm-feature-detect` 固定 1.8.0，后续版本引入当前 Electron/Node 无法解析的语法，升级前必须验证实际对齐。

### 字幕编辑、字体与播放模式（2026-11-11）

- 音频设置增加 `sentenceFontFamily`、`sentenceFontSize`，默认系统字体、26px；可选 Arial、系统字体和苹方，字号 18–42px。右侧句子的快捷字号按钮也更新同一持久化设置。
- 自定义选词通过复制事件及 Ctrl/Cmd+C 写入剪贴板；没有选词时复制当前句。输入框、笔记文本的原生选择及设置窗口不被覆盖。
- 字幕编辑在弹窗中显式保存或取消，保留段 ID、句子起止时间和已有笔记。修改文字后移除旧词时间映射和 IPA 缓存，使用现有按句子时间估算的词选区，避免沿用与新文字不匹配的识别时间戳。
- 提供全文/单句播放切换。全文模式使用原始完整音频，播放中自动同步当前字幕，可点击字幕从该句开始连续播放；单句模式使用句子裁切、选区循环和剪刀编辑。切换模式暂停并清空选区。
- 本次移除的是音标界面入口；旧字幕数据中的 IPA 字段保留兼容，不再自动请求音标。

选词键盘规则：单词按钮获取焦点时，Space 必须阻止原生按钮点击并调用当前选区的播放/暂停，不得缩减选区；忽略长按重复 keydown。字幕设置增加 `sentenceFontWeight`（400/700），与字体、字号统一持久化。

全文播放与显示分离：`hooks/use-continuous-audio.ts` 管理完整文件的连续播放及选区边界；WaveSurfer 始终显示当前句的裁切波形。播放模式切换不改用全文件波形，全文跨句时只更新当前句波形和播放位置，完整音频不重建。句子波形相对时间与完整音频绝对时间通过当前句起点换算。

播放位置同步：全文播放的波形使用 requestAnimationFrame 读取真实媒体时间并逐帧同步，不依赖低频 timeupdate；暂停、结束和卸载取消帧任务。时间仍来自媒体 currentTime，不使用虚假的插值进度。选区边界也在帧回调检查，保留暂停和循环行为。

音轨点击与编辑补充：普通点击波形定位后立即播放；拖选仍只设置选区。全文和单句都允许剪刀编辑，沿用当前句前后各 3 秒及起止边界保存逻辑。全文媒体在无源时不初始化，取消播放的异步结果不得作为媒体故障处理。

音频分类：`audios.category` 为可空字符串，启动时仅在缺少该字段时 addColumn；不重建或清空旧表。`audios-update-category` 支持单条/批量（最多 1000 条）并校验所有 ID，在事务中保存分类；空白清除分类，名称最多 80 字。列表提供逐行修改与勾选后批量修改，可输入新分类或选择已有分类。

笔记编辑改为按需：顶部“填写笔记”按钮请求打开输入框并聚焦，默认不展示输入框；保存后收起。已有笔记编辑同样打开输入框，句子/词组笔记列表仍保持展示。

### 独立音频分类管理（2026-11-11）

- `audio_categories` 独立表保存 id、唯一 name 和 Sequelize 时间字段。启动时将已有音频分类回填入表，空分类不会因没有音频而丢失。
- 顶部“管理分类”独立于行选择，弹窗可新增/改名/删除；勾选音频后另显示批量“修改分类”，逐行修改仍保留。音频分类分配只能选择已建立的分类或“未分类”，新建通过管理弹窗完成。
- 分类改名在事务中同步更新 `audios.category`，删除在事务中先清除音频分类再删除分类记录，不删除音频；重名由唯一索引拒绝。
- IPC：`audio-categories-list/create/rename/delete`，通过 preload 暴露类型化方法。词汇分类目前保存在词汇设置中，音频按用户要求使用独立数据表。

音频列表展示名称、分类和添加时间。操作列支持编辑资源名称及分类和删除，点击音频名称打开详情。修改名称更新库内显示文字，播放继续使用原文件路径。

字幕列表的句子按钮获得焦点时，Space 同样需要 preventDefault/stopPropagation 并调用 togglePlay，禁止原生按钮点击重新触发 chooseSentence；长按重复不触发。Enter 保持原生选择句子行为。之前仅对单词按钮处理空格，不能覆盖句子列表焦点场景。

### 管理字幕与纯文本对齐（2026-11-11）

- 播放页通过“管理字幕”统一打开编辑、重新生成、输入和导入操作。管理弹窗列出全部字幕时间及可编辑文字，支持统一保存。修改文字保留段 ID 和起止时间，仅失效已改句的词映射和 IPA 缓存。未保存关闭有放弃确认，保存前检查字幕是否已被其他操作修改。
- 无字幕时以覆盖窗口的弹窗提供生成、输入和导入三种方式，导入按钮直接列出 LRC、TXT、SRT、VTT，成功保存后打开播放区。替换已有字幕需确认，取消文件选择或解析、对齐失败时保留现有字幕。导入段使用新 ID，避免旧笔记错挂。
- `shared/lrc-subtitles.ts` 解析 LRC 时间标签、毫秒 offset、多标签行和同时间重复行；结束时间取下一标签，最后一句取媒体长度（无长度时暂取后 3 秒），空标签可用作结束标记。
- `main/services/text-subtitle-alignment.ts` 使用本地 Echogarden DTW/eSpeak 对齐原始音频与 TXT 或粘贴文本。存在空行时每段输出一条字幕，组内可包含完整问答及普通换行。只有普通换行或连续文本时，由 Intl.Segmenter 按句号、问号、感叹号断句。词级时间来自对齐结果，原文标点保留在字幕中。
- TXT 对齐依赖本地 FFmpeg 与 Echogarden 首次使用的语音资源，文本与音频不一致时允许时间不准，用户可在管理弹窗及剪刀编辑中修正。纯文本导入不使用按字数估算整段时间的伪对齐。

### 每次生成选择模型与粘贴文本（2026-11-11）

- 经用户确认，“引擎选择”指现有 Whisper Tiny/Base/Small/Medium 模型，不新增其他识别引擎。生成/重新生成前使用 `transcription-model-dialog.tsx` 选择，未下载条目带下载箭头与进度；下载成功刷新状态后才可确认。
- `transcribeAudio(audioId, modelId?)` 将本次模型明确传到主进程，校验模型 ID，覆盖本次识别的默认模型及自定义路径，不修改全局偏好。未提供参数的旧调用仍沿用设置。
- “输入字幕”弹窗支持直接输入或粘贴完整文本，提交后通过 `subtitle-align-text` 执行 Echogarden DTW 对齐。接受最多 200000 字符的有效文本，对齐失败保留原字幕及当前草稿。
