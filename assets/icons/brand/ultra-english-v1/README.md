# UltraEnglish 品牌设计

日期：2026-11-13

## 设计方向

以 U 字母和双声波构成标志，连接 UltraEnglish 品牌名称与音频学习功能。青绿色沿用应用现有配色，深灰字标适合浅色界面。macOS 图标使用同一符号，搭配白色圆角底座及轻微浮雕质感。

## 交付

- `ultra-english-logo.png`：透明底横版品牌 Logo。
- `ultra-english-mark.svg`：同系列 U/双声波符号的透明矢量实现，用于侧栏，不包含白色底座。
- `ultra-english-macos.png`：透明外边距的 macOS 图标原图。
- `ultra-english.icns`：传统 macOS/Electron 打包图标，包含 16–1024 像素规格。
- `ultra-english.iconset/`：各尺寸 PNG。

已接入客户端：主页使用横版 Logo，侧栏使用透明 SVG 符号，认证界面使用方形图标；`assets/icons/icon.png`、`icon.icns` 与 `icon.ico` 分别用于窗口/Dock 和各平台打包。PNG 为位图；ICNS 为静态图标，不包含 Icon Composer 动态材质层。
